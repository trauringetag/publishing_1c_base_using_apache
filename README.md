# Установка и публикация базы на веб-сервере (Работа с HTTP-сервисами)

Данное руководство описывает процесс установки и базовой настройки веб-сервера Apache в операционной системе Windows для последующей публикации информационных баз 1С:Предприятие и работы с HTTP-сервисами.

## Пошаговая инструкция

### Шаг 1. Скачивание дистрибутива

Скачайте архив с веб-сервером Apache с сайта:  

[https://www.apachelounge.com/download/](https://www.apachelounge.com/download/)

> ️ **Важно:** Убедитесь, что разрядность скачиваемого Apache (32 или 64 бита) строго совпадает с разрядностью установленной платформы 1С:Предприятие.

### Шаг 2. Распаковка файлов

Распакуйте скачанный архив. Переименуйте извлеченную папку в `Apache24` и переместите её в корень диска `C:\`.  

Итоговый путь к папке должен выглядеть так: `C:\Apache24\`

### Шаг 3. Настройка конфигурационного файла

1. Откройте файл `C:\Apache24\conf\httpd.conf` в любом текстовом редакторе (рекомендуется Notepad++ или VS Code).

2. Найдите в файле строку (обычно она закомментирована символом "#"):

   ```
   #ServerName www.example.com:80
   ```

3. Раскомментируйте её и измените значение:

   ```
   ServerName localhost:80
   ```
4. Сохраните и закройте файл.

### Шаг 4. Установка и запуск службы Apache

Откройте командную строку (CMD) или PowerShell от имени администратора и выполните следующие команды по очереди:

1. Установка службы Apache:

   ```
   C:\Apache24\bin\httpd.exe -k install
   ```

2. Запуск службы:

   ```
   net start Apache2.4
   ```

### Шаг 5. Проверка результата

Откройте любой веб-браузер и перейдите по ссылке:

   ```
   http://localhost/
   ```

Результат: "It works!".

### Удалить текущую службу Apache

Откройте командную строку от имени администратора и выполните:

1. Остановить службу:

   ```
   net stop Apache2.4
   ```
   
2. Удаление службы Apache:

   ```
   C:\Apache24\bin\httpd.exe -k uninstall
   ```
